# requirements
python (www.python.org)

run  
pip install -r requirements.txt  
in command prompt in the downloaded folder  

### OR

run  
pip install (library)  
for every library in requirements.txt

# run local server
run the app.py file  
in the info that is printed paste the running on link in your web browser of choice. the link is probably http://127.0.0.1:5000/

# stop the server
press ctrl+c in terminal where you ran app.py
